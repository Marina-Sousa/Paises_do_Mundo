# 🌍 Países do Mundo

Uma aplicação web simples e intuitiva feita em **HTML, CSS e JavaScript** que permite pesquisar e visualizar informações gerais sobre diversos países.

---

## 🚀 Funcionalidades

* 🔍 **Busca Dinâmica:** Pesquisa de países por nome.
* 📊 **Exibição de Dados:** Apresenta dados e informações gerais sobre o país pesquisado.
* 🎨 **Interface Limpa:** Design simples e focado na usabilidade.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação da página.
* **CSS3:** Estilização e layout responsivo.
* **JavaScript (Vanilla):** Lógica de busca, manipulação do DOM e consumo de dados.
